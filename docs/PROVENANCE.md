# Provenance

The public README of [anson10/Path-Finding-Visualiser](https://github.com/anson10/Path-Finding-Visualiser) was consulted for the general idea of comparing pathfinding algorithms visually.

RouteLab's source, report styling, maps, documentation and tests were written from scratch for this repository with AI assistance. No implementation code, fonts, screenshots, icons or other assets from the reference repository were incorporated. The checked-in preview is generated from RouteLab's own report.

Only the C++ standard library is used in application code. Compilers, CMake and GitHub Actions are development tools, not bundled application components. Their own terms still apply to those tools. This document does not claim that the underlying algorithms or the general project idea are novel.
